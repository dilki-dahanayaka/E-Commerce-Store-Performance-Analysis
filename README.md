# E-Commerce-Store-Performance-Analysis

## 🎯 Project Objective
The main objective of this project is to model the complete e-commerce customer journey—from viewing a product to cart addition and final purchase conversion. By evaluating behavioral bottlenecks and revenue distribution patterns, the project delivers actionable, data-driven business recommendations to optimize website UI/UX and enhance store inventory management.

---

## 📁 Repository Structure & Modular Architecture
This repository is designed following production-level modular architecture standards to ensure high code maintainability and reusability:

```text
my_internship_project/
│
├── data/
│   └── events.csv                  # Raw uncleaned e-commerce dataset (~885k rows)
│
├── notebooks/
│   ├── 1_data_cleaning.py          # Step 1: Handles missing data and anomalies
│   ├── 2_kpi_and_eda.py            # Step 2: Calculates revenue metrics and top brands
│   └── 3_funnel_analysis.py        # Step 3: Processes conversion drop-offs & behaviors
│
├── outputs/
│   ├── cleaned_ecommerce_data.csv  # Production-ready datasets generated by backend
│   ├── funnel_chart.png            # Statically rendered conversion funnel chart
│   └── [analytical_summary_csvs]   # Exported KPI reports
│
├── src/
│   └── dashboard_app.py            # Interactive Streamlit Web Frontend
│
├── run_all.py                      # Central pipeline automation orchestrator
